## Allowed Tools

You may use:

- IDEs and shells;
- Docker and Redis inspection;
- application logs and metrics;
- internet documentation;
- LLM assistants such as Claude, ChatGPT, Copilot, or Cursor.

The constraint is evidentiary: a claimed root cause must be demonstrated with
runtime evidence and reproduction.
